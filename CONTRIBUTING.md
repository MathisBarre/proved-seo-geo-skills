# Contributing

Contributions are welcome when they make the skill more useful without widening a claim beyond its evidence.

1. Read [the evidence policy](skills/proved-seo-geo/references/evidence-policy.md).
2. Open a source or claim-review issue before a broad content change when possible.
3. Use source IDs and state the claim, tier, scope, method, limitations, and verification path in the PR.
4. Run `npm run validate` and `npm run watch:sources:validate`.
5. Do not add a new secondary source domain as an established authority in the same change that first discovers it.

For automated contributions, follow [the agent maintenance protocol](docs/agent-maintenance.md). Pull requests from the quarterly watch are drafts by design and require a human evidence decision.
